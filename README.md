# Book Bot
### Overview
Book Bot is a Python command-line utility for analyzing text in literary works. This tool extracts statistical insights from novels and documents, revealing word frequency patterns and character usage.

### Features
Analyzes text files with robust error handling
Generates word frequency reports sorted by occurrence
Provides character distribution analysis
Produces clean, formatted reports

## Getting Started
Prerequisites

Python 3.6+
No external dependencies

### Installation
```bash# Clone the repository
git clone https://github.com/yourusername/book-bot.git
cd book-bot
```
### Usage
```bash
# Basic usage
python main.py path/to/your/book.txt

# Example with sample text
python main.py samples/frankenstein.txt
```
### Sample Output
```
--- Book Analysis Report ---
Total words: 7832
Unique words: 2245
Most common words:
1. "the": 523 occurrences
2. "and": 341 occurrences
3. "of": 318 occurrences
```
